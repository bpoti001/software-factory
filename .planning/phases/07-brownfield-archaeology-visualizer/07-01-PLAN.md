# Phase 7 Plan 01: Brownfield Archaeology, Retro-ADR Synthesis & Visual Intelligence Engine

**Goal**: Implement `DRD-01` through `DRD-06` governed by `ADR-0001`, `ADR-0007`, and `ADR-0008` so the Software Factory can analyze any already-built repository, extract a full dependency X-Ray and Git archaeology report, synthesize sensor-compliant Retro-ADRs and domain glossary terms, and generate 5-lens Mermaid visual diagrams, a cognitive `ARCHITECTURE_TOUR.md`, and an interactive `explorer.html`.

## Tasks
1. **Red Phase (Public Seam Tests)**: Write `tests/archaeology-visualizer.seam.test.mjs` testing `analyzeCodebase` (`DRD-01`), `mineGitArchaeology` (`DRD-02`), `synthesizeRetroAdrs` (`DRD-03`), `generateArchitectureVisuals` (`DRD-04`), `generateArchitectureTour` (`DRD-05`), and `generateInteractiveExplorerHtml` (`DRD-04.2`) strictly through `src/modules/discovery/index.mjs` and `src/modules/visualizer/index.mjs`.
2. **Green Phase — Discovery & Archaeology (`src/modules/discovery`)**: Implement `xray-scanner.mjs`, `git-archaeology.mjs`, and `adr-synthesizer.mjs`, and export `analyzeCodebase`, `mineGitArchaeology`, and `synthesizeRetroAdrs` from `src/modules/discovery/index.mjs`.
3. **Green Phase — Visualizer & Cognitive Tour (`src/modules/visualizer`)**: Implement `mermaid-visuals.mjs`, `architecture-tour.mjs`, and `html-explorer.mjs`, and export `generateArchitectureVisuals`, `generateArchitectureTour`, and `generateInteractiveExplorerHtml` from `src/modules/visualizer/index.mjs`.
4. **CLI Wiring & Dogfooding (`src/cli/factory.mjs`)**: Add `factory analyze`, `factory adr-synthesize`, and `factory visualize`, add CLI integration tests, and run `factory analyze --visualize` on the Software Factory repo to generate `docs/architecture/VISUAL_ARCHITECTURE.md`, `docs/architecture/ARCHITECTURE_TOUR.md`, and `docs/architecture/explorer.html`.
