# Phase 5 Plan 01: Amazon AI-DLC Synthesis Architecture & Capability Engine

**Goal**: Deliver AI-DLC capabilities: Intent Profiles in `sizing`, Deterministic Sensors in `sensors`, Self-Learning Rule Loop in `learning`, Brownfield Practices Discovery in `discovery`, and Operations & Rollback Gate in `review`, governed by `ADR-0001` and `ADR-0007`.

## Tasks

### Task 1: Red Phase — Author Public Seam Tests for AI-DLC Capabilities (`tests/aidlc.seam.test.mjs`)
- Test Intent Profiles and orthogonal depth in `classifyTaskSize`.
- Test deterministic sensors: `checkRequiredSections`, `checkTraceability`, `checkClaimSources`, and `runSensors`.
- Test self-learning loop: `recordLearnedRule`, `checkRuleConflict`, `listLearnedRules`.
- Test brownfield practices discovery: `discoverPractices`.
- Test operations rollback gate in `assessMergeDanger` for `One-Way Door` changes.

### Task 2: Green Phase — Implement Deep Modules & Seams

3. Implement `src/modules/learning/lib/rules.mjs` and `index.mjs`.

6. Update `src/cli/factory.mjs` to add `learn` and `discover` subcommands, run sensors and emit `.planning/VERIFICATION_RECEIPT.json` in `verify`, and verify receipts in `pr-report`.
