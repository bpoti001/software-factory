# Requests for Comments (RFC Ledger)

> **When to Use an RFC vs. an ADR:**
> - Use an **ADR (`/create-adr`)** for a single, bounded architectural decision (choosing a library, defining a module seam, picking a schema pattern).
> - Use an **RFC (`/create-rfc`)** when a feature or refactor spans multiple bounded contexts/teams, breaks external API contracts, requires a multi-batch **Expand-Contract** migration, or needs decomposition into a DAG of **Jira Tracer-Bullet Tickets**.
